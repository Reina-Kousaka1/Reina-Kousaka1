**Status:** Active development

### [LuaJIT — experimental fork](https://github.com/Reina-Kousaka1/LuaJIT)

An upstream-based LuaJIT fork exploring compatibility with newer Lua language features, with an initial focus on reproducible builds, regression tests and ARM64.

This is **not yet a Lua 5.5-compatible runtime**. The upstream LuaJIT code and its original copyright and license notices remain credited to their respective authors.

`C` · `LuaJIT` · `Compilers` · `ARM64`

**Status:** Early research and development

An experimental programming language drawing on ideas from **Java**, **Elixir** and **C++**: static types, structured programming, actors, supervision, asynchronous tasks and lower-level runtime capabilities.

Its evolving toolchain includes a lexer, parser, AST, type checker, interpreter and CLI.

**Status:** Long-term development — progressing when time allows, not production-ready
